## Findings considered and rejected

- Moving every button callback into a hook: small navigation and local input
  callbacks are easier to read beside their JSX and have no shared behavior.
- Moving the root layout's session effects: its expiry timer and tested deep
  link coordinator already have clear lifecycle ownership.
- Moving routine persistence out of `features/routines/`: the app intentionally
  stores routine and intake domain data on the phone, with the current provider
  as their shared state boundary.
